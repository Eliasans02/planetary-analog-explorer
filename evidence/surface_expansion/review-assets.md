# Independent review of expanded source assets

Reviewed 2026-11-14 by the terrain-analysis agent, who did not author the acquisition/export implementation. Scope: `expand_surface_sites.py`, `test_surface_expansion.py`, the four new public provenance records, actual cached source bytes and receipts, catalog geometry, and expansion evidence. No acquisition/export implementation or asset edits were made. This is a bounded source-integrity and geometry review, not an upstream DEM accuracy certification or global terrain validation.

**Result: no material findings in the delivered four sites.**

Checks performed independently of `source_pixels` and its tests:

- Rehashed every retained range payload against its public receipt, checked exact byte lengths and Content-Range bounds/complete-product lengths. All four sets retain consistent ETag and Last-Modified values within each product. The two complete lunar TIFF hashes match their assembled contiguous chunk payloads; all source offsets cover the stated complete TIFF sizes with no gaps. The Mars identity explicitly covers only the 129 retained complete source rows, not the full IMG.
- Parsed Mars label RECORD_BYTES, image record pointer, PC_REAL/32-bit type, declared valid minimum/maximum and null value. Independently calculated first requested row offsets and inclusive end offsets, then decoded little-endian Float32 rows and sliced the native columns. Lunar crops were independently read from the complete TIFFs using their recorded windows; TIFF scale=1 and offset=0 were confirmed.
- Compared all 66,564 added heights and every mask byte to source-derived results: Float64 subtraction of valid crop minimum followed by Float32 storage, zero for invalid cells. All four actual windows contain 16,641 valid samples. Native rows and source spacing are retained; no resampling or filling occurs.
- Independently derived source-center pixel coordinates from the affine transform and center-selection rule. Inverted lunar south polar stereographic using radius 1,737,400 m and analytic spherical formulas; inverted Mars equirectangular using each label's radius, standard parallel and central meridian. All published center latitudes/longitudes agree within 1e-10 degree. Crop pixel-center origin agreement is within floating arithmetic precision (largest observed discrepancy approximately 3.4e-13 m). Moon frame naming comes from the cited NASA product page/README, and Mars retains the label planetocentric east-longitude/local-radius geometry without claiming a frame transformation.
- Recomputed the six pre-expansion canonical record/source hashes in the preservation fixture; all match. Existing asset hash checks and the recorded original-source tests cover old buffer preservation. The acquisition implementation replaces only the four named added records, retains original record dictionaries, and does not create global height coverage.
- Reviewed failure behavior for exact HTTP ranges, changed cached payloads, dimensions/type, scale/offset, rotated grids, source meter axes, insufficient valid samples and invalid source center. Existing focused tests already cover malformed range responses and full source/output pixel comparisons; no redundant full test-suite run was performed for this review.

Informational provenance detail: a complete lunar receipt inherits HTTP headers from the initial header request, so its Content-Range/Content-Length describe that header response. The receipt explicitly identifies a complete TIFF assembled from separately retained verified ranges, and its complete-product size/hash are correct. Consumers should use the per-range receipts when interpreting HTTP response headers.

Limitations: local hashes establish the identity of the acquired bytes, not an independent publisher-signed checksum. This review did not reacquire source products or validate upstream photogrammetry, instrument returns, vertical accuracy, per-sample uncertainty, or exact physical ground distances. Source provider interpolation, projection approximation and unverified lunar absolute vertical datum remain disclosed. No complete HiRISE IMG hash, synthetic global terrain, landing suitability, analog ranking or habitability claim was found.
