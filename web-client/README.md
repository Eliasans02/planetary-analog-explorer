## Coordinate Frames & Heightfield Layout

- **Local ENU Frame (`local_enu_x_east_y_up_z_south`)**: `+X` East, `+Y` Up, `+Z` South, 1 unit = 1 metre.
- **Row-Major Grid Ordering**: `row = 0..height-1` runs `north_to_south` (`z = extent_m[1] + row * spacingZ_m`); `col = 0..width-1` runs `west_to_east` (`x = extent_m[0] + col * spacingX_m`), where `spacing = (max - min) / (count - 1)`.
- **Vertical Origin**: Binary `float32_le` values in `heights` are local offsets in metres relative to `origin.elevation_m`. `sampleHeight()` returns local `y` directly for Three.js camera/mesh collision; absolute datum elevation (`y + origin.elevation_m`) is computed only for HUD display.
- **NoData Handling**: Nodes with `valid_mask === 0` are excluded from triangle generation and collision sampling (`sampleHeight()` returns `null`). Zero (`0`) is never treated as a missing sentinel.

## Engineering Budgets

- Max DPR: `1.5` (with adaptive hysteresis step-down on sustained frame times > 24 ms).
- Max terrain mesh grid: `257 × 257` nodes (`66,049` nodes).
- Max Gaussian splats: `250,000` splats.
- Max active ground scene assets: `64 MiB`.

## Empty State & Real Dev_A Dataset

With no `public/data/locations_dataset.json` present, the UI enters an honest empty/error state with a Retry button and renders only the neutral **Schematic Reference Globe** in Orbit mode. No fabricated coordinates, terrain, or similarity scores are generated.

`npm run lint` is an alias for TypeScript typechecking (`npm run typecheck`); no separate JavaScript/TypeScript linter is configured.
